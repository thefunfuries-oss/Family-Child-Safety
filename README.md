# Family Child Safety

A secure family safety platform for parents and children.

## Features

- Parent registration and login
- Child/device pairing
- Current location sharing
- Location history
- Online/offline status
- Battery status
- SOS alerts
- Geofence alerts
- Permission-based camera, video and voice features
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
